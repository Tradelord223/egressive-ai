# Egressive AI

An essay proposing **egressive** as a lens for understanding the shift from
language models that *return text* to agents that *push actions outward* —
issuing commands, writing files, calling APIs, and changing the state of the
world.

📖 **Read it:** https://tradelord223.github.io/egressive-ai/

It is an opinion piece, not a survey. The one external result it leans on (the
Darwin Gödel Machine) is cited directly; the rest is argument, and the framing
of *egressive* as a term is the author's own.
